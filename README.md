# Sales-Segmentation-RFM-Analysis-PowerBI
📊 Project Overview

This Power BI project analyzes customer sales data using RFM (Recency, Frequency, Monetary) analysis to identify valuable customer segments and understand sales performance.
The dashboard provides insights into sales trends, customer behavior, customer segmentation, and product category performance.

 
## 🎯 Objectives

- Analyze monthly sales trends
- Segment customers using RFM analysis
- Identify Champions, Loyal Customers, Big Spenders and At-Risk customers
- Analyze customer frequency, recency and monetary value
- Compare category-wise customer distribution
- Provide an interactive customer-level analysis

## 🛠️ Tools & Technologies

- Power BI
- DAX
- Power Query
- Microsoft Excel / CSV
- Data Visualization
- RFM Customer Segmentation

# RFM Analysis

The project uses RFM Analysis to evaluate customer value based on three dimensions:

Metric :- Description

Recency :- How recently a customer made a purchase 
Frequency :- How frequently a customer purchases 
Monetary :- How much a customer spends 

Based on these metrics, customers are categorized into meaningful segments such as:

- 🏆 Champions
- 💙 Loyal Customers
- 💰 Big Spenders
- ⚠️ At Risk
- 👥 Others
